# Security Policy

Stellaryn is currently pre-alpha and has not been audited.

Passing Stellaryn is not a security audit and does not prove that a contract upgrade is safe to deploy.

Security-sensitive areas include malicious Wasm/spec input, unsafe path handling, subprocess execution, report injection, Git safety, and denial-of-service behavior caused by Stellaryn itself.

Do not publish credentials, private contract source, or exploit details in a public issue. Establish a private reporting channel with the repository owner before sharing sensitive material if no private vulnerability-reporting flow is available.
